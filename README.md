# Retail Portfolio Dashboards

Hildreth Real Estate Advisors retail-portfolio investor + operator dashboards. Static-site repo deployed via Netlify.

## Live URLs

Once Netlify is connected to this repo and subdomains are configured:

| Property | Subdomain | Path fallback |
|---|---|---|
| 68-100 Old Riverhead Rd · Westhampton Beach | `68-100.<your-domain>` | `/68-100/` |
| 193 + 231 Commack Rd · Commack | `commack.<your-domain>` | `/commack/` |

The apex / root URL serves a portfolio landing page with tiles linking to each property.

## Repo structure

```
.
├── index.html              # Portfolio landing page (apex domain)
├── 68-100/
│   └── index.html          # 68-100 Old Riverhead Rd dashboard
├── commack/
│   └── index.html          # 193 + 231 Commack Rd combined-entity dashboard
├── netlify.toml            # Hostname → path rewrites + cache headers
└── README.md
```

Each dashboard is a single self-contained HTML file (Tailwind + Chart.js via CDN). All financial data is embedded as JSON inside the file.

## Updating the dashboards

The HTML files are generated by the upstream pipelines:

```bash
# 68-100 Old Riverhead Rd
cd "/Users/jasonbreitstone/Documents/Claude/Projects/68-100 Old riverhead Road "
python3 scripts/01b_pull_gl_monthly.py    # refresh AppFolio data (optional)
python3 scripts/02_normalize.py
python3 scripts/03_compute_metrics.py
python3 scripts/06_build_budget.py
python3 scripts/05_build_dashboard.py     # writes dashboard/index.html

# Commack
cd "/Users/jasonbreitstone/Documents/Claude/Projects/Commack Road Combined"
python3 scripts/01b_pull_gl_monthly.py    # optional
python3 scripts/02_normalize.py
python3 scripts/03_compute_metrics.py
python3 scripts/06_build_budget.py
python3 scripts/05_build_dashboard.py
```

Then copy the generated dashboards into this repo and push:

```bash
cp "/Users/jasonbreitstone/Documents/Claude/Projects/68-100 Old riverhead Road /dashboard/index.html" \
   /Users/jasonbreitstone/Documents/GitHub/Retail-portfolio/68-100/index.html
cp "/Users/jasonbreitstone/Documents/Claude/Projects/Commack Road Combined/dashboard/index.html" \
   /Users/jasonbreitstone/Documents/GitHub/Retail-portfolio/commack/index.html

cd /Users/jasonbreitstone/Documents/GitHub/Retail-portfolio
git add -A
git commit -m "refresh dashboards"
git push
```

Netlify auto-deploys on push.

## Netlify setup (one-time)

1. New site → Import from Git → choose `Retail-portfolio`
2. Build settings: leave empty (no build step). Publish directory: `.`
3. Site settings → Domain management → Add domain
   - Add your apex domain (e.g. `hreaportfolio.com`)
   - Add subdomain aliases: `68-100.hreaportfolio.com` and `commack.hreaportfolio.com`
4. The hostname rewrites in `netlify.toml` will route each subdomain to the right dashboard.

If you use a different domain than `hreaportfolio.com`, edit the `Host` arrays in `netlify.toml` to match.
